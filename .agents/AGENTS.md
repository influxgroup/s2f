# Human UI Design Directives (Linear / Stripe Aesthetic)

1. Natural Human Copywriting
   - Write clear, professional, human copy. Avoid dramatic AI jargon (e.g., use "Contact Us", "Submit Inquiry", "View Details" instead of "Direct Memorandum Transmitted" or "Forensic Telemetry").

2. Minimalist Badge Policy
   - Limit badges/pills to max 1 per page section, reserved ONLY for functional status (e.g. "Active", "Pending"). Do not place decorative uppercase badges above headings.

3. Clean Neutral Palette & Whitespace Hierarchy
   - Use clean, modern neutral tones (e.g., Slate/Zinc #0F172A, #F8FAFC, #E2E8F0).
   - Avoid heavy background glow blurs, radial gradients, or metallic border lines.
   - Rely on generous 8px grid whitespace (p-6, space-y-6, gap-6) and clean 1px slate borders instead of nested container cards inside container cards.

4. Icon Restraint
   - Only use icons for interactive controls (inputs, buttons, dropdown arrows) or primary navigation.
   - Do not wrap static text lines inside colored circle icon boxes.

5. Typography-First Contrast
   - Establish hierarchy using font weight (font-semibold/font-bold), font size, and text color contrast (e.g., text-slate-900 heading vs text-slate-500 body text) rather than putting every paragraph in a separate box.
